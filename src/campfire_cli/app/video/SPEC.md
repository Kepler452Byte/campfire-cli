# Video App SPEC

本模块提供实验性的本地视频素材准备、草稿校验与图文交付，不承诺高可用性或自动内容保真，不解析在线链接。

- `cli/` 解析参数与翻译异常；跨 App 的文档治理检查由 `AppContainer` 编排。
- `schema/` 定义素材与草稿的数据契约；`service/` 负责预览、校验、审批及安全写入用例。
- `service/video_protocol.py` 定义消费方媒体接口；`common/media/` 实现隔离进程、解码、抽帧和本地语音转写，不解释文档治理规则。
- 可选媒体依赖在处理时加载；不隐式下载模型，不上传视频，不修改来源，不覆盖已有正文。
- `video setup` 是视频环境唯一初始化入口：依赖安装与默认模型下载纳入一次预览和确认，最后通过离线子进程验证实际加载。已有部分复用，失败不卸载已安装依赖。`prepare` 仅处理视频，缺环境提示初始化，不安装或下载。
- Python 依赖从包元数据的 `video` extra 读取，禁止复制依赖清单。只在当前隔离环境安装缺失的二进制包，固定已有版本，不重装 Campfire 或自动修改系统 Python；无法安全安装时停止并报告。
- 模型默认位于 Campfire 用户目录的 `models/<模型仓库名>/`，支持 `CAMPFIRE_HOME` 与处理时显式 `--model`。下载到临时目录，必要文件非空后锁内安装；不覆盖已有目录。验证失败保留模型并报告，已有本地模型直接离线使用。
- 实验性质不降低路径、哈希、写入确认与冲突保护要求。结构校验不代替 Agent 对转写和图片的语义核验。
- 中间素材默认存放于 `<CAMPFIRE_HOME>/materials/<视频SHA-256>/`，`--output` 可指定 Workspace 外的新目录；预览不创建目录，已有素材不覆盖、不自动清理。原视频只读且不复制；最终正文和选定图片交付到 Vault 后不依赖中间素材目录。
