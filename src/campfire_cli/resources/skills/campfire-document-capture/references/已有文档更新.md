# 已有文档更新

1. 确认候选文档是当前主题的权威对象；需要关系上下文时运行 `document inspect --path <path>`。
2. 保持原 Project 和 Domain，除非用户明确要求重新归属。
3. 只改人工正文时先读取文档开头和最近 `_领域.md` 的人工维护规则，再做最小 Edit 并读取修改区域验证。
4. 修改 Frontmatter 或类型时使用 `document apply`；只改标题时使用 `document rename`，跨 Domain 移动时使用 `document move`。
5. 不修改 `AUTO-GENERATED` 标记内内容，只执行写命令实际返回的 follow-up。
