# 项目内容沉淀

用于只对当前项目成立的实现事实、方案和过程记录。

1. Project 已明确时直接复用；尚未定位时，当前代码目录用 `workspace project resolve --path <cwd>`，已知项目名用 `workspace project list/show`。
2. 读取源码、配置和测试，区分当前事实、目标方案与讨论建议。
3. 目标目录未知才用 `workspace domain list --project <id>` 获取候选，只在语义唯一时选择子 Domain，否则询问用户。
4. 同主题已有文档优先更新；没有时按有效 Profile 创建。

不要把项目局部约束沉淀为通用知识，也不要仅凭目录名称推断 Project。
