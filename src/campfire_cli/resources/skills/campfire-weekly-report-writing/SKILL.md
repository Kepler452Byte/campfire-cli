# 工作周报写作

先通过 `campfire workspace space list` 找到 work 类型 Space，再通过 Domain 声明和现有 `type: weekly-report` 文档确定工作日志与周报位置；不得根据固定目录名推断。

## 输入与依据

1. 读取本周工作日志，确认完成事项、实际结果、已发现问题和待办。
2. 读取上一周周报，识别承接关系并检查上周计划进展。
3. 缺少工作日志、周期或必要上下文时明确指出，不编造成果、难点、指标或计划。

## 输出规则

- Frontmatter 与文件名前缀通过 Campfire Document Profile 和类型定义读取，不在 Skill 复制。
- 正文使用“复盘目标、问题分析、下一步行动计划”；保持简洁、成果导向，不写成日志流水。
- 完成成果必须有日志、任务、项目文档或用户材料支持；计划和当前事实不能混写。
- 新建前检查同周期周报是否存在，除非用户明确要求，否则不修改历史周报。
