# Campfire 收件箱分流

处理 `_收件箱/用户输入/` 中的原始材料。先读取 `campfire-workspace-governance`，再读取候选领域的 `_领域.md`。

## 工作流

1. 保留原文，识别内容是长期知识、项目事实、工作记录还是尚无法判断的材料。
2. 只在已有正式领域中选择目标；创建顶级领域、合并内容或删除原文必须由用户确认。
3. 给出目标空间、领域、类型、文件名、摘要、理由和置信度。
4. 归属明确时形成默认未审批的维护建议，不直接移动。
5. 空间、领域、权威性或合并关系存在歧义时，在 `_收件箱/待用户确认/` 生成可读确认单，并保持原文不动。
6. 用户决定转为已审批计划后才执行；完成后同步 MOC 并关闭确认单。

## 边界

- `high` 只表示可以生成待审批计划，不表示可以跳过审批。
- `medium` 或 `low` 必须请求确认。
- 确认单必须链接原文、列出候选及一个明确问题，不能代替正式知识文档。
