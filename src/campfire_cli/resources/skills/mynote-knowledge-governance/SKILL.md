# mynote 知识笔记治理

目标是把随手记录沉淀为可检索、可复用的长期知识，同时保留用户原文和判断依据。

## 工作流

1. 读取 `campfire-workspace-governance`、目标笔记及候选领域 `_领域.md`。
2. 选择唯一主物理领域；跨主题关系使用链接、标签和自动关系表达，不复制文件。
3. 建议清晰标题、摘要、单选 `type` 和必要标签；无法从原文确定的事实不得编造。
4. 与现有笔记可能重复、冲突或需要合并时只报告候选，交由用户确认。
5. 通过维护计划预检和执行确定项，再同步 MOC、链接和关系。

## 边界

- 不因单个关键词创建新领域。
- 项目当前事实优先留在 `mywork`；只有可独立复用的知识才沉淀进 `mynote`。
- 不手工编辑 MOC 自动生成区域。
