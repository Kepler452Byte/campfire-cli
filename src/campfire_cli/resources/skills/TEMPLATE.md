# 面向 CLI 的 Skill 模板

编写规范见 [SPEC.md](SPEC.md)。复制下面骨架到具体 Skill 的 `SKILL.md`，替换占位内容并删除不适用章节；本文件是开发模板，不是运行时 Skill，不同步到用户 Skill 目录。

SOP 保留“流程总览”和“执行步骤”：ASCII 图展示分支与顺序，正文说明操作与边界，二者维护在同一文件。简单流程画短链，不为凑模块增加查询、命令或审批。路由类 Skill 不虚构命令示例，只读类 Skill 不套用写入门禁。

````markdown
---
name: tool-task-name
description: "[完成什么任务]；适用于[触发场景]，不用于[容易混淆的场景]。"
---

## 执行门禁

- 操作在用户授权范围内；已有授权不重复询问。
- 目标唯一；关键歧义未解决时不写入。
- 事实、计划与推断明确区分，不编造缺失信息。
- [本任务特有的安全要求。]

条件已满足就直接执行，不把门禁变成固定查询链。

## 上下文与契约

- [环境与目标]：已知时复用；未知时通过[明确入口]获取。

- [路径基准与环境选择方式。]

## SOP

### 流程总览

```text
接收任务
|-- 目标与信息明确 -> 选择操作
`-- 信息缺失 -> 按需查询或询问 -> 仍有歧义则停止

选择操作
|-- 只读 -> 查询 -> 整理结果
`-- 写入 -> 执行前提满足后，按 CLI 契约执行
           |-- 失败或结果不确定 -> 核查，不盲目重试
           `-- 成功 -> 必要后续动作 -> 回报结果
```

### 执行步骤

1. [定位或复用目标，说明可跳过的发现步骤。]

3. [执行命令；仅当 CLI 支持时安排预览、哈希或确认。]
4. [检查关键返回；失败时停止依赖该结果的后续操作。]
5. [完成必要后续动作，不固定追加全量检查。]

## 异常与停止条件

- 输入错误：[依据返回信息修正，不猜参数。]
- 关键事实缺失：[询问什么，暂停哪些操作。]
````
