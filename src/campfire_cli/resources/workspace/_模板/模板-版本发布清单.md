# 模板使用说明（不复制到实际文档）

适用类型：`plan`，实际清单放各项目的 release 目录。创建时保留下面的「格式规范」到实际文档顶部，将示例项目、版本、工作和证据替换为真实内容，不复制本模板的 Frontmatter。下面是虚构演示，不代表实际发布计划；按需扩展或裁剪时同步调整规范。

> [!info] 格式规范
>
> - 顶部展示发布状态、目标版本和实际发布日期。状态只使用 `计划中` / `实施中` / `验收中` / `已发布` / `已取消`；尚未发布时日期为 `—`。
> - 核心工作一项一个可验收结果；验收项通过后才勾选，并记录实际结果与证据，未验证则说明。范围变化同步更新目标和工作，不把撤销项标成完成。
> - 发布记录按下方结构维护，不预设发布渠道。用户确认范围不等于授权发布；实际发布成功后才标记已发布，填写发布日期与发布证据。
>
> ```markdown
> ## 验收
>
> - [ ] <可验证的完成条件>
>   - 结果与证据：<实际结果和依据；未验证则说明>
>
> ## 发布记录
>
> - 实际发布结果：<尚未发布 / 实际结果及限制>
> - 发布证据：<实际版本、提交或发布地址；未发布则写无>
> ```
