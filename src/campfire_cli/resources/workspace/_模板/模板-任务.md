# 模板使用说明（不复制到实际文档）

适用类型：`task`。创建时保留下面的「格式规范」到实际文档顶部，将示例标题和正文全部替换为真实内容，不复制本模板的 Frontmatter。下面是虚构演示，不代表已有任务或用户授权；无变更时省略变更记录。简单待办可裁剪章节，同时裁剪对应规范，不删除用户明确要求。

> [!info] 格式规范
>
> - 当前目标、进展和下一步保持最新；工作项完成、验收通过后才勾选。未验证明确说明，撤销项标明取消。
> - 重要目标、范围、验收或名称变化按日期追加记录，写明原因与真实确认依据；同步更新当前内容，不保留过时待办或聊天流水。
> - 整体任务状态维护在 `task_status`，文档关系维护在 `related_docs`；正文只记录实际进展。
>
> ```markdown
> ## 验收与结果
>
> - [ ] <可验证的完成条件>
>   - 结果与证据：<实际结果和依据；未验证则说明>
>
> ## 关键变更记录
>
> - YYYY-MM-DD：<变化>；原因：<原因>；确认依据：<填写真实确认来源，尚未确认则标明待确认，不执行变更>。
> ```

# 示例任务：验证工具安装

## 当前目标与范围

- 目标：确认工具可以安装并运行版本命令。
- 范围：只验证本机，不测试其他设备，不发布新版本。

## 当前进展与交接

- 已完成：尚未开始验证。
- 剩余与阻塞：待执行安装和版本检查；暂无已知阻塞。
- 下一步：按项目安装说明，在隔离环境中执行安装。

## 工作清单

- [ ] 在隔离环境中安装工具。
- [ ] 运行版本命令并记录结果。

## 验收与结果

- [ ] 安装成功，版本命令返回目标版本。
  - 结果与证据：尚未验证。

## 关键变更记录

- YYYY-MM-DD：<实际变化>；原因：<实际原因>；确认依据：<填写真实确认来源>。
