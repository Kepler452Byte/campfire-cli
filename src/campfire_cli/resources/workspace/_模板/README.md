# 文档模板原则

模板是最小写作参考，不是必须填满的表格。

- **只留必要结构**：保留完成该类文档目的所必需的内容，不预置所有可能的章节或专项门禁。
- **按需扩展与裁剪**：Agent 可根据实际任务调整正文，但不能擅自省略用户明确要求的内容，也不能把新增建议写成已确认要求。
- **不为模板编造事实**：没有材料的部分可省略或说明待确认，不为填满章节虚构工作、结论或证据。
- **尊重已有文档**：维护时保留合理结构，不因模板更新强制重排全文。
- **区分使用与维护**：扩展当前文档不等于修改共享模板。创建或修改共享模板需用户要求或确认，不把单次任务的特殊需求自动固化成通用规则。

通用模板集中在本目录；局部模板仅在明确指定时使用，不逐层查找或自动合并。每份模板顶部只说明适用类型与自身特殊要求，通用原则不重复抄写。

## 模板如何带入实际文档

- **模板使用说明不复制**：适用类型、复制方式等只留在模板中。
- **格式规范随文档保留**：说明这篇文档如何持续维护，放在实际文档顶部，让后续人和 Agent 无需回查原模板。
- **示例正文全部替换**：demo 只展示写法，不把示例名称、日期、状态、授权或证据当成事实；没有真实内容时省略或注明待确认。
- **裁剪时同步规范**：删除不需要的章节，也删去对应规范。共享模板后续变化不自动覆盖已有文档。

Frontmatter 由 CLI Profile 约束，正文模板不增加字段、校验规则或命令。本说明供人类维护和 Agent 按需查阅，不是每次写文档的必读前置步骤，也不是模板注册表。
